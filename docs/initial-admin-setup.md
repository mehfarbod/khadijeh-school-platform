# راه‌اندازی نخستین مدیر ارشد

این فرایند فقط برای نصب تازه‌ای است که هنوز هیچ `SUPER_ADMIN` ندارد. اسکریپت
تکرارپذیر است: اگر مدیر ارشد از قبل وجود داشته باشد، اطلاعات حساب، رمز و Staff
او را تغییر نمی‌دهد و فقط کاتالوگ مجوزها را همگام می‌کند.

1. `DATABASE_URL` و `NEXTAUTH_SECRET` امن را در محیط اجرا تنظیم کنید.
2. مقادیر زیر را فقط در محیط همان اجرای bootstrap قرار دهید؛ آنها را در Git یا
   فایل‌های اشتراکی ذخیره نکنید:

   - `BOOTSTRAP_ADMIN_NATIONAL_ID`
   - `BOOTSTRAP_ADMIN_MOBILE`
   - `BOOTSTRAP_ADMIN_FIRST_NAME`
   - `BOOTSTRAP_ADMIN_LAST_NAME`
   - `BOOTSTRAP_ADMIN_PASSWORD`

3. رمز اولیه باید حداقل ۸ نویسه و متفاوت از کد ملی باشد.
4. فرمان زیر را یک بار اجرا کنید:

   ```bash
   pnpm bootstrap:super-admin
   ```

5. مدیر ارشد باید در اولین ورود رمز را تغییر دهد. سپس متغیرهای
   `BOOTSTRAP_ADMIN_*` را از محیط موقت اجرای فرمان حذف کنید.

برای همگام‌سازی امن و idempotent مجوزها بدون ساخت حساب جدید:

```bash
pnpm seed:permissions
```

این اسکریپت‌ها هیچ رمز، hash، کد ملی یا شماره همراهی را در خروجی چاپ نمی‌کنند.
